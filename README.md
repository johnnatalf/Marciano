# O Robô Marciano 👽

Projeto desenvolvido em **Kotlin** para a disciplina de Desenvolvimento de Aplicações Móveis I

## 🎯 Objetivo
O objetivo principal deste projeto foi desenvolver um programa simulando um robô com respostas limitadas e capacidade de processamento matemático básico...

## 🛠️ Tecnologias e Conceitos Utilizados
* **Kotlin** (Compatibilidade nativa)
* **Programação Orientada a Objetos:** Herança, Polimorfismo e Interfaces
* **Estrutura de dados:** Coleções, Arrays e Lambdas
